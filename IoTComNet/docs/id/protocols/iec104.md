# IEC 60870-5-104

**Ringkasan.** IEC 60870-5-104 ("IEC 104") adalah protokol telekontrol antara master SCADA dan gardu, RTU, pembangkit
energi terbarukan, serta gateway jaringan listrik, di TCP port 2404. Controlling station (master) memulai transfer
data, menjalankan interogasi umum untuk mengetahui semua nilai, lalu hanya menerima perubahan, masing-masing dengan
tanda waktu CP56Time2a. Master mengoperasikan pemutus, saklar, tap changer, dan set point dengan perintah, biasanya
sebagai select-before-operate.
`IoTCom.Net.Protocols.Iec104` menyediakan:

- `Iec104Client`, controlling station:
  - STARTDT/STOPDT, dan tabel nilai terakhir setiap titik (`Points`, `PointReceived`)
  - interogasi umum dan per grup, interogasi counter, baca
  - perintah single, double, dan regulating step serta set point (float, scaled, normalized), langsung atau
    select-before-operate, menunggu konfirmasi dan terminasi aktivasi
  - sinkronisasi jam
  - hanya-baca secara bawaan: perintah, set point, dan sinkronisasi jam memerlukan `AllowCommands()`
- `Iec104Server`, controlled station:
  - tabel titik (`Define`, `Update`) dengan perubahan spontan bertanda waktu ke setiap koneksi yang sudah memulai
    transfer data, grup, dan counter
  - handler perintah per alamat (`MapCommand`), select-before-operate wajib (opsional) dengan batas waktu seleksi
  - jawaban negatif untuk tipe, penyebab, common address, dan alamat objek yang tidak dikenal, serta end of
    initialisation
- Link APCI yang dipakai keduanya: pemeriksaan urutan N(S)/N(R), jendela k dan w, timer t1/t2/t3, TESTFR.
- Codec: `Iec104Apdu`, `Iec104Asdu`, `Iec104Object`, `Cp56Time2a`, 38 type identification, `Iec104Framing`, dan
  frame lane (`Iec104Apdu.Describe`).
- `Iec104SubstationSimulator`, RTU bay penyulang 20 kV:
  - pemutus, pemisah, dan saklar pentanahan dengan interlock, serta trip proteksi
  - pengukuran, on-load tap changer, counter energi, dan set point daya reaktif

Codec-nya punya kembaran Rust yang di-fuzz (`rust/crates/iotcom-iec104`) dan diperiksa dengan vektor
`/conformance/iec104.json` yang sama, yang berasal dari referensi Python independen.

## Kapan dipakai

- Membangun SCADA, historian, atau front end analitik jaringan listrik yang membaca gardu dan RTU.
- Gateway dari IEC 104 ke MQTT, OPC UA, atau basis data, atau dari protokol lapangan (Modbus, DLMS) ke master IEC 104.
- Menguji master SCADA terhadap RTU simulasi, atau RTU terhadap master berskrip.

## Instalasi

```bash
dotnet add package IoTCom.Net.Protocols.Iec104 --prerelease    # juga bagian dari meta-package IoTCom.Net
```

## Mulai cepat

```csharp
using IoTCom.Net.Protocols.Iec104;

await using var scada = Iec104Client.Create(o => o.UseTcp("10.0.0.5"));      // port 2404, CA 1, hanya-baca
await scada.ConnectAsync();                                                  // STARTDT
foreach (var p in await scada.InterrogateAsync()) Console.WriteLine(p);      // interogasi umum
scada.PointReceived += p => Console.WriteLine(p);                            // perubahan spontan bertanda waktu
```

Mengoperasikan peralatan:

```csharp
await using var op = Iec104Client.Create(o => o.UseTcp("10.0.0.5").AllowCommands());
await op.DoubleCommandAsync(5001, on: false, selectBeforeOperate: true);    // buka pemutus: select, execute, terminasi
await op.SetpointAsync(6001, 1.5);                                           // C_SE_NC_1
```

Sebuah stasiun:

```csharp
await using var rtu = Iec104Server.Create(o => o.UseTcp(2404));
rtu.Define(2001, Iec104TypeId.MeasuredFloat, 20.1, "Busbar voltage (kV)");
rtu.Define(1001, Iec104TypeId.DoublePoint, 2, "Breaker");
rtu.MapCommand(5001, Iec104TypeId.DoubleCommand, c => { if (!c.IsSelect) rtu.Update(1001, c.Command.Value, cause: Iec104Cause.ReturnRemote); return true; });
await rtu.StartAsync();
rtu.Update(2001, 20.3);    // dikirim sebagai M_ME_TF_1 dengan tanda waktu
```

## Keamanan

Perintah IEC 104 membuka dan menutup pemutus di jaringan bertegangan. Klien bersifat hanya-baca secara bawaan dan
melempar `ReadOnlyModeException` untuk perintah, set point, dan sinkronisasi jam sampai `AllowCommands()` dipanggil.
`iotcom iec104 command` memerlukan `--allow-write` dan meminta konfirmasi pada stasiun sungguhan. Gunakan
select-before-operate untuk switchgear, dan hubungkan hanya ke stasiun yang Anda berwenang operasikan. IEC 104 tidak
punya keamanan sendiri; di jaringan sungguhan, jalankan di dalam VPN atau dengan TLS IEC 62351 yang diterminasi oleh
gateway.

## Alat

```bash
iotcom iec104 serve                                 # RTU bay penyulang di TCP 2404
iotcom iec104 gi -h 127.0.0.1                       # tabel interogasi umum (--group 1–16, --counters)
iotcom iec104 monitor --sim                         # interogasi, lalu perubahan spontan
iotcom iec104 read 2001 --sim
iotcom iec104 command double 5001 off --sbo --sim --allow-write
```

## Pengujian

Uji codec memakai contoh byte:
- keenam frame U dan frame S;
- aktivasi C_IC_NA_1 yang klasik;
- float bertanda waktu dengan CP56Time2a (termasuk bit invalid dan summer time; 31 Februari dan tahun di atas 99 ditolak);
- step position dengan bit transient, nilai normalized dan scaled, serta double point dalam urutan (SQ = 1);
- counter dengan flag sequence, carry, dan adjusted, perintah dengan select, dan set point;
- APDU dan ASDU yang rusak, serta stream yang terpotong dengan noise.

Uji sesi menjalankan simulator lewat transport dalam memori:
- interogasi umum, per grup, dan counter, baca, serta alamat yang tidak dikenal;
- trip proteksi yang tiba sebagai data spontan bertanda waktu;
- select-before-operate yang diwajibkan, pemutus yang melewati "intermediate", dan interlock yang menolak pensaklaran
  tidak aman;
- tap changer, batas set point, alamat perintah yang tidak dikenal, sinkronisasi jam, dan penolakan mode hanya-baca;
- interogasi 300 titik dengan k = 2 dan w = 1, TESTFR setelah t3;
- stasiun yang menutup link saat acknowledgement berhenti (t1) dan saat terjadi kesalahan urutan;
- jawaban negatif untuk tipe, penyebab, dan common address yang tidak dikenal.

Ke-53 vektor bersama (termasuk 10 frame rusak) dijalankan di suite uji C# dan Rust, dan suite Rust juga menyandikan
ulang setiap frame yang valid. Codec Rust di-fuzz sebanyak 1,6 juta kali tanpa temuan.

## Keterbatasan

Belum ada transfer file, pemuatan parameter (P_ME), C_RD dengan grup, penanganan redundancy group, maupun keamanan
IEC 62351. Perubahan spontan tidak disangga selama belum ada master yang memulai transfer data. Transmisi siklik
(periodik) diserahkan ke aplikasi (`Update(..., Iec104Cause.Periodic, force: true)`). Pasangan serialnya,
IEC 60870-5-101, belum diimplementasikan.
