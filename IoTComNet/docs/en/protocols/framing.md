# Framing and CRC

**Summary.** The small, stateless pieces every embedded link needs: frame boundaries (SLIP, COBS, HDLC, lines) and
corruption detection (CRC, LRC). Allocation-free, streaming, and verified against shared test vectors.

## When to use it

- Talking to a microcontroller over UART/USB with your own message format.
- Implementing or debugging a protocol that specifies a CRC (Modbus, DNP3, MAVLink, HDLC, M-Bus, BLE, RTCM…).
- Splitting text protocols (NMEA, AT commands, ASTM) into lines.

## The CRC catalogue

`CrcAlgorithm` is a table-driven engine for widths 8–64 using the Rocksoft model parameters. `CrcCatalog` holds 23
presets; each passes its catalogue check value for ASCII `123456789`.

| Width | Presets |
|---|---|
| 8 | CRC-8/SMBUS, CRC-8/MAXIM-DOW (1-Wire), CRC-8/SAE-J1850 |
| 16 | ARC, MODBUS, IBM-3740 (CCITT-FALSE), XMODEM, KERMIT, IBM-SDLC (X.25/HDLC), MCRF4XX (MAVLink), DNP, EN-13757 (wM-Bus), USB, MAXIM-DOW |
| 24 | OPENPGP, LTE-A (CRC-24Q, RTCM 3), BLE |
| 32 | ISO-HDLC (CRC-32), ISCSI (CRC-32C), MPEG-2 (STM32), BZIP2 |
| 64 | XZ, ECMA-182 |

```csharp
ulong crc = CrcCatalog.Crc16Modbus.Compute(frame);
var mavlink = CrcCatalog.Find("mavlink")!;            // aliases: modbus, x25, crc32c, rtcm, ...
var custom = new CrcAlgorithm(new CrcParameters("MY-CRC", 16, 0x1021, 0x1D0F, false, false, 0, 0xE5CC));
ushort crc16 = Crc16.Modbus(frame);                    // ushort convenience
byte lrc = Lrc.Compute(body);                          // Modbus ASCII
```

## Framing codecs

| Codec | Delimiter | Overhead | Notes |
|---|---|---|---|
| `Slip` (RFC 1055) | `0xC0` | up to 2× | optional leading END |
| `Cobs` | `0x00` | ≤ 1 byte per 254 | no zero bytes inside frames |
| `Hdlc` | `0x7E` | escape `0x7D`, FCS-16 appended | async HDLC / PPP style |
| `LineFraming` | `\n` (strips `\r`) | none | NMEA, AT, ASTM |

All implement `IFrameEncoder` and the streaming `IFrameDecoder`, which works on `ReadOnlySequence<byte>` straight from
a `PipeReader` (frames split across reads are fine, invalid frames are skipped and the stream recovers).

```csharp
await pipe.Writer.WriteFrameAsync(new Cobs(), payload);
await foreach (var frame in transport.Pipe.Input.ReadFramesAsync(new Cobs())) Handle(frame);
```

## Testing

`/conformance/crc.json` (115 vectors), `cobs.json` (the canonical COBS examples) and `slip.json` are generated by an
independent bit-by-bit reference (`conformance/generate.py`) and executed by the C# and Rust test suites.
